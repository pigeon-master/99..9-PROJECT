# 99..9 PROJECT

Vite + TypeScript + Three.js로 만든 비둘기 산책 화면입니다. React, Vue 등의 프레임워크를 사용하지 않습니다.

흰 배경에서 비둘기 100마리가 서로를 피하며 빠르게 걷습니다. 상단 중앙에는 Helvetica 폰트의 `99..9 PROJECT` 타이틀, 좌측 상단에는 조작 안내를 표시합니다. 일반 비둘기 97마리(차콜 33, 시나몬 32, 아이보리 32)와 자르반, 핑크 갸루, 보행기 아기 비둘기가 각각 한 마리씩 있습니다. 새 외형은 총 100마리 안에서 일반 개체를 대체하도록 `src/main.ts`의 `specialStyles` 목록으로 관리합니다. 외부 3D 모델이나 이미지 다운로드 없이 동작합니다.

갸루 비둘기는 기존 비둘기 원형에 매트 라이트 브라운 웨이브 헤어, 핑크 리본, 3단 프릴과 레이스 미니드레스, 속눈썹·볼터치, 진주 목걸이와 하트 장식, 긴 핑크 네일팁을 더한 개체입니다. 장식은 기존 머리·몸통·날개·발 관절에 연결되어 걷기, 먹이 먹기, 들어 올리기와 놓기 동작을 동일하게 지원합니다. `createPigeon(id, 'gyaru')`로 생성하며 기본 스타일은 기존 모델을 유지합니다.

렌더링 부담을 줄이기 위해 날개 한쪽을 39개에서 8개 형상으로, 꼬리깃을 9개에서 5개로 간소화했습니다. 작은 디테일의 메시 분할 수도 줄였으며, 몸통과 머리의 기본 형상 및 상호작용은 유지합니다.

아기 비둘기는 보행기 버전만 무리에 포함하며, 보행기 없는 버전은 일반 비둘기로 교체했습니다. `createPigeon(id, 'walker')`로 생성하며 민트색 트레이, 청록색 하부 프레임, 연두 체크 좌석, 앞쪽 장난감과 6개 쌍바퀴를 사용합니다. 다리 보행과 함께 이동하고 실제 이동 거리·회전 방향에 따라 바퀴가 구릅니다. 정지하거나 들어 올리면 바퀴는 멈추며, 홀드·산란·알 클릭 기능은 다른 특수 비둘기와 공유합니다. `node scripts/test-walker.mjs`로 바퀴의 이동·회전·정지 동작을 검사합니다.

쪽쪽이 비둘기는 참고 이미지의 회색 깃털, 흰색 방패와 하늘색 버튼·흰 고리의 공갈 쪽쪽이, 민트색 허리 밴드와 흰 기저귀를 구현했습니다. `createPigeon(id, 'baby')`로 생성하며, 쪽쪽이는 머리 관절을 따라 움직이고 기저귀는 몸통에 부착됩니다. 갸루와 같은 홀드 배설·산란·알 클릭 동작을 사용하고 산란 이력은 각각 독립적으로 관리합니다.

- 비둘기를 클릭한 채 유지하면 들어 올립니다.
- 누른 채 드래그하면 위치를 옮기고, 놓으면 바닥에 착지합니다.
- 아직 산란하지 않은 갸루 또는 쪽쪽이 개체를 연속으로 홀드하면 1초와 2.15초에 꼬리 아래에서 아이보리색 액체 배설을 합니다. 각 배설은 0.45초 동안 가느다란 물줄기 하나로 이어지고, 중력으로 떨어진 액체는 바닥에 작고 윤기 있는 자국을 남깁니다.
- 두 번째 배설이 끝난 뒤 2초 더 홀드하면(총 4.6초) 옅은 상아색 알 한 개가 꼬리 아래에서 떨어집니다. 알은 3배 확대 버전에서 가로·세로·높이를 각각 30% 축소했으며, 배설물보다 밝은 색과 은은한 베이지 외곽선으로 바닥 및 자국과 구분됩니다. 착지 후 무작위로 휘는 경로를 따라 2~3바퀴 구르고 감속한 뒤 옆으로 안정되며 멈춥니다. 한 번의 홀드당 배설 두 번, 알 한 개만 발생합니다.
- 바닥의 알 위에 커서를 올리면 그 자리에서 1.5배로 커집니다. 알을 직접 클릭하면 0.9초 동안 화면 중앙으로 날아오며 도착할수록 빠르게 커집니다. 중앙에서는 화면의 약 60% 영역에 맞추되 모바일에서도 화면 밖으로 잘리지 않도록 크기를 조절합니다.
- 중앙의 알을 다시 클릭하면 껍질에 금이 갑니다. 바깥 영역 클릭 또는 Escape로 바닥에 돌려놓을 수 있으며, 금은 유지됩니다. 알 앞을 비둘기가 가리면 비둘기가 먼저 선택되므로 비둘기를 옮기거나 노출된 알 표면에 커서를 대야 합니다.
- 알을 낳은 개체는 페이지를 새로고침하기 전까지 다시 산란하지 않습니다. 다시 들어 올리면 홀드마다 무작위로 정한 2~3회의 배설만 합니다(3초, 4.15초, 세 번째가 있으면 5.3초). 산란 이력은 개체별로 메모리에만 기록합니다.
- 중간에 놓으면 남은 순서는 취소됩니다. 다시 잡으면 3초부터 시작하며, 이미 나온 액체와 알은 계속 떨어집니다. 알이 나오기 전에 놓았다면 산란 기회는 유지됩니다. 자국과 알은 남으며 장시간 사용 시 가장 오래된 것부터 재사용합니다(자국 80개, 알 24개).
- 터치 화면에서는 손가락으로 누른 채 이동할 수 있습니다.
- 우클릭하면 클릭 위치 주변에 곡물 모이를 뿌립니다. 우클릭한 채 드래그하면 이동 경로를 따라 모이가 떨어집니다.
- 근처 비둘기들은 각각 0~2초의 반응 지연 후 가까운 모이를 찾아 몸을 돌리고 빠르게 달려갑니다. 서로 간격을 두고 쪼아 먹으며, 모이가 없어지면 다시 배회합니다.

목의 앞뒤 움직임과 양발의 교대 보행을 연결한 절차적 애니메이션입니다. 사진 스캔 모델이나 생체역학 시뮬레이션은 아닙니다.

초기 위치는 화면 전체에서 서로 간격을 두고 무작위로 배치합니다. 이동할 때마다 행동 반경과 방향을 새로 정하고, 주변 개체 및 예약된 목적지가 적은 공간을 우선 선택해 한곳에 몰리는 현상을 줄입니다.

## 실행

Node.js 22.12 이상을 설치한 환경에서 실행하세요.

```sh
npm install
npm run dev
```

Windows PowerShell에서 `npm.ps1` 실행 정책 오류가 발생하면 `npm` 대신 `npm.cmd`를 사용하세요. 각 명령은 별도 줄에서 실행합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

## 빌드

```sh
npm run build
```

PowerShell에서는 `npm.cmd run build`로 실행할 수 있습니다.

TypeScript 검사 후 `dist/`에 배포 파일을 생성합니다.

## 구조

- `src/main.ts`: 장면, 조명, 이동 및 드래그 상호작용
- `src/movement.ts`: 임의 목적지 선택, 제한된 회피와 이동 경로
- `src/feeding.ts`: 곡물 렌더링, 개별 모이 탐색, 달리기와 섭식 상태
- `src/pigeon.ts`: 비둘기 모델과 색상 변형
- `src/gyaru.ts`: 갸루 개체의 헤어·의상·장식·네일 모델링
- `src/hold-effects.ts`: 홀드 시간, 액체 낙하·바닥 자국, 알 낙하·구름·정지
- `src/egg-focus.ts`: 알의 중앙 이동·확대·금 효과와 화면 크기 대응
- `src/picking.ts`: 비둘기와 알의 깊이 순서 및 가림을 반영한 클릭 판정
- `src/style.css`: 화면 구성과 반응형 스타일
- `public/`: 그대로 복사할 정적 파일
- `templates/`: 향후 사용할 템플릿 보관 폴더
- `index.html`: 웹 진입점
- `tsconfig.json`: TypeScript 설정
- `package.json`: 의존성과 실행 스크립트

이동 경로 회귀 검사는 Node.js 22.18 이상에서 `node scripts/test-movement.mjs`로 실행합니다. 데스크톱·모바일 영역에서 100마리 모두 90초 동안 넓게 이동하는지 검사합니다.

`node scripts/test-feeding.mjs`는 곡물 분포, 반응 지연, 달리기, 점진적인 소모와 배회 복귀를 검사합니다.

`node scripts/test-hold-effects.mjs`는 갸루 전용 홀드 시간, 배설 두 번, 바닥 자국, 지연 산란, 알의 낙하·구름·정지, 홀드 해제와 재시작을 검사합니다.

`node scripts/test-egg-interaction.mjs`는 알 호버, 비둘기에 의한 가림, 중앙 비행·확대, 두 번째 클릭의 금, 모바일 크기 대응과 바닥 복귀를 검사합니다.
